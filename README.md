# Appistore

Appistore is a responsive app-discovery storefront starter.

## Current features
- Responsive dark interface
- Featured app cards and category filters
- Live search
- App details modal
- Static demo listings (no APK downloads are provided yet)

## Run locally
Open `index.html` in a browser.

## Deploy
The project is a static site and can be deployed on Vercel from this repository. No build command or output directory is required.
